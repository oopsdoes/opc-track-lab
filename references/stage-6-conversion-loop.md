# 阶段 6 · 转化闭环（含建盘收尾）

> 蒸馏自 easychen/opc-methodology 官方技能 `opc-conversion-loop`、`opc-asset-ops`、`opc-dashboard-review` 及书中"基础设施"章节精要，中文改写版（2026-10）。冲突时以官方为准。

## 目标

设计"**怎么触达、怎么承接、怎么成交**"的路径结构。关键不只是流量，而是有没有**承接和成交动作**——没有承接动作不算闭环。

## 边界

**不做**：具体帖子选题/文案、产品包装话术、运营 SOP——出现即拉回："这些属于内容资产阶段的工作。现在先把转化路径的结构确认好，后面的内容才有方向。"

## 三步结构（按顺序确认）

1. **触达（在哪被看见）**：目标用户最常出现的渠道。渠道选择三规则：优先**已有基础的**、**用户集中的**、**你能可持续产出内容的**；**不要一开始铺太多平台**，收缩到 1~2 个。
2. **承接（怎么接住）**：线索来了用什么动作接（私信、表单、社群、邮件列表…）。没有承接动作 = 流量白白漏掉。
3. **成交（第一单怎么发生）**：低摩擦成交动作——先卖低价入口还是直接高客单？怎么完成第一次付费？

## 常见转化路径模式（3 选 1 或组合 + "4. 我有自己的方案"）

- 内容 → 私信 → 咨询 → 成交
- 内容 → 表单 → 诊断 → 成交
- 内容 → 低价产品 → 升级服务
- 搜索流量 → 落地页 → 预约 → 成交

每条说明适用情况、优点、代价。书中"出海小闭环"的对应路径（SEO 引流 → 落地页 → 订阅/广告变现）见 overseas-loop.md。

## 落盘检查点（用户确认后立即执行）

1. `opc-doc/outputs/07-conversion-loop/channel-strategy.md` — 目标渠道选择及依据
2. `opc-doc/outputs/07-conversion-loop/content-plan.md` — 内容触达方式**类别**（非具体选题）
3. `opc-doc/outputs/07-conversion-loop/conversion-path.md` — 完整路径：触达 → 承接 → 成交
4. `opc-doc/state/current-stage.json` → `{"stage":"07-conversion-loop","status":"completed","next_stage":"execution","summary":"一句话主转化路径"}`；`decisions.json` 追加

## 建盘期收尾（阶段 6 落盘后必须说的收尾话术）

> "建盘期已完成（01 资源盘点 → 02 利基定位 → 03 价值主张 → 04 商业模式 → 06 MVP → 07 转化闭环）。现在进入**执行期**——按你的转化路径实际去做。
>
> 出现以下情况再回来：
> - **运营卡住、找不到问题在哪** → 经营复盘（本技能 V1 提供轻量版，见下）
> - **有东西开始重复出现、想系统化** → 资产沉淀（精要见下）"

## 附 A · 资产沉淀精要（触发式，非线性下一步）

**触发信号**："写了很多类似内容可以整理成模板了""这套流程用了好几次该固化""客户问题都差不多想做个标准回答"。**没有实际运营产出时不进入**——先去执行。

- 六类资产：内容 / 产品 / 渠道 / 数据 / 方法论 / 品牌
- 知识结构最少包含：资产清单、方法模板、表达模板、历史案例、渠道经验、数据记录
- 判断优先沉淀方向（方法模板优先 / 内容资产优先 / 渠道线索优先，3 选 1 + 自定义）
- 落盘：`opc-doc/outputs/08-asset-ops/asset-inventory-[YYYYMMDD].md` + `action-plan-[YYYYMMDD].md`（带日期，不覆盖历史）
- **允许给模板结构框架，"填写内容"由用户完成**（除非用户明确要求代写）

## 附 B · 经营复盘精要（触发式）

**触发信号**：运营一段时间感到卡顿、想做有结构的回顾、转化/留存明显下滑。**刚建完盘没执行过 → 不做假复盘**，提醒先去执行。

- 三个诊断问题：最近最卡的一步？是**没人来、没人买，还是做完不复用**？（对应需求/转化/资产三类瓶颈）
- 瓶颈三选一走 **Jev 判断关**：AI 初判+判卷模型复判（`scripts/jev-check.py`）双列呈现，分歧项用户终判下一周期唯一重点；未配置判卷模型时标注「单阅卷」
- 生成 3 个瓶颈判断（需求验证不足 / 转化路径不顺 / 资产沉淀太弱…）+ 依据 + "4. 我有自己的方案"
- 确认**下一周期唯一优先重点**（保持单一优先级）
- 落盘：`opc-doc/outputs/09-dashboard-review/review-[YYYYMMDD].md` + `reviews/dashboard.json`（追加不覆盖）
- 复盘发现前置阶段有根本问题 → 可回退对应阶段（说明理由，只更新受影响的输出，不重做全部）

- [ ] 用户确认主转化路径
