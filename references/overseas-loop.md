# 出海三步闭环（快速模式手册）

> 来源：公众号「coding AI智造副业」《出海赚美分、找点子：三个GitHub武器》（https://mp.weixin.qq.com/s/pyw77_QyH63XfdZlma1dgA ，2026-10 抓取）。本手册蒸馏其方法论框架。
> ⚠️ 文中提到的工具、价格、星数均为**发文时点信息，以原文为准**；工具会过时，使用前让 AI 现查或用户自验。**本手册讲的是闭环方法（不易过时），不是工具快照。**

## 定位：六阶段的出海快进版

| 三步闭环 | 对应六阶段 | 关系 |
|----------|-----------|------|
| 第 1 步 找点子 | ≈ 阶段 2 利基定位 | 求快：三武器直接扫；求稳：走完整六阶段 |
| 第 2 步 起应用 | ≈ 阶段 5 MVP | 3 天上线的工具型 MVP |
| 第 3 步 跑起来 | ≈ 阶段 6 转化闭环 | SEO 引流 + 变现正向循环 |

给要速度的用户用本模式；给要严谨的用户用完整六阶段。两者可混用：快速闭环跑出数据后，回头补阶段 1/2 的深度分析。

## 第 1 步：找点子（三武器联动）

1. **Awesome 给方向地图**（https://github.com/sindresorhus/awesome ）：不知道做什么 → 翻"清单的清单"，27 个大类里看哪个生态活跃、哪些工具被社区反复筛选
2. **独立开发者列表给真实案例**（1c7，主版面 40%+ 面向海外）：`gh-fetch.py cases --track <关键词>` 找 3~5 个同类，看别人做了什么、哪些方向被验证过
3. **Zread.ai 读懂案例**（https://zread.ai ）：把 github.com 换成 zread.ai，3 分钟看懂同类项目的架构和思路——**不是照抄代码，是理解思路后用自己的方向重新实现**。隐藏用法：选技术栈前先看 3~4 个同类开源项目的架构对比

抄作业的正确姿势：看到 Listlift 做 Etsy 卖家工具 → 想亚马逊卖家工具；看到 GeoMock 做地址生成 → 想跨境注册辅助；确认"这个赛道被验证了，找细分空白，不是重新发明"。

## 第 2 步：起应用（3 天上线）

- **轻量后端**：PocketBase（单文件后端，SQLite 内置）/ Supabase（开源 Firebase：数据库+认证+存储）
- **AI 编程**：Cursor / Claude Code / Windsurf 等，前端 Next.js 或 Nuxt
- **免费部署**：Vercel / Cloudflare Pages，配域名
- 节奏参考：第 1 天选方向+找同类+看架构；第 2 天起最小产品；第 3 天上线部署

## 第 3 步：跑起来（变现与正向循环）

- 引流：SEO（3~5 篇基础内容起步）+ 社区推荐 + Product Hunt + 目录站
- 变现：订阅 / 广告 / 联盟
- **核心是正向循环**：先有流量 → 再有哪怕很小的一笔收入 → 有收入就有动力优化 → 优化带来更多流量。原文实话：第一年收入大多不亮眼，关键在循环转起来

## 四个出海模式（从案例库归纳，也可当六维评分外的速查透镜）

1. **AI 工具站群模式**：围绕热门 AI 模型（生图/生视频/生音乐）批量建垂直工具站，SEO 引流。核心不是技术，是**速度 + SEO + 选对细分词**——抢在别人前面占住细分词
2. **SaaS 订阅模式**：面向特定人群的订阅工具（如竞品研究自动化、雅思作文批改、YouTube 无脸频道生成、Etsy 卖家内容引擎）
3. **简单工具 + 广告模式**：解决一个全球通用的小刚需（地址生成、全球假期查询、证件照），广告变现
4. **平台/导航模式**：目录站、导航站（免费提交 SaaS、AI 工具发现）

共同特征：**小而快**——一人或两三人、3 天到 2 周上线的最小可行产品，先跑起来再迭代。

## 快速模式的使用边界（硬规矩）

- 快速闭环**不替代**阶段 1 资源盘点和四问筛选——至少口头过一遍四问再动手
- 上线只是验证的开始，不是终点；MVP 成功标准见 stage-5 手册
- 出海合规自负：政策、支付、版权、平台规则，用户自行确认
